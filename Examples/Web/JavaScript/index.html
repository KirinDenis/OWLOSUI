OWLOSUI - the web ladder

Five programs in JavaScript. Each page loads the OWLOSUI core, a Rust program compiled to WebAssembly, and draws what it says on a canvas.

  1. 1. Hello, world - A window, words, a button: the whole shape of a program.
  2. 2. Notes - An editor that keeps its text, finds and replaces, and asks before leaving.
  3. 3. Calculator - A keypad of real buttons, modes, and the arithmetic kept apart.
  4. 4. BASE-Z 47 - A game: sixty warehouses drawn cell by cell on a canvas.
  5. 5. OWLOS UI Demo - Everything the kit has, in one program, with a menu bar.

The same ladder in C# is in Examples/Desktop/CSharp; the client these pages use is lib/js/owlosui.js.
